
###        🛠️ En este proyecto utilizaremos principalmente los fondos.

#          🧩 Cuerpo de la web
 -> Debe tener una imagen de fondo, preferiblemente un pattern.

#          🧠  Cabecera 
-> Borde Fino Negro, color de fondo azul y espaciado interior de 10 px.

#           👥 Encabezado primer nivel
 -> Texto Blcanco

#           👥 Encabezado de tercer nivel
 -> Borde 3 veces mas grueso, color verdoso, color de fondo tomate, margen interior de 10 px y text blanco.
